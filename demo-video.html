ReliefGrid demo

Prioritize response before the crisis spreads.

ReliefGrid turns scattered emergency signals into a ranked dispatch brief for local teams working with scarce supplies.

Prototype Static web app
Runs on HTML, CSS, JavaScript
Output Dispatch brief and PNG handoff
Use case Heatwave, flood, clinic outage

Walkthrough

What the demo shows

  1. Local teams start with an incident, time window, transport mode, available supplies, and zone signals.
  2. ReliefGrid ranks zones using severity, vulnerable residents, population exposure, comms reliability, resource fit, and travel friction.
  3. The canvas map shows the relief hub, priority route, and ranked response zones.
  4. The dispatch brief explains the top mission, first-hour actions, and fallback plan in copy-ready language.
  5. The prototype works locally with save, copy, and PNG export paths for fast handoff.
