## How To Submit

1. Open the submission workspace above.
2. Click `Create project` for a new build, or `Import from portfolio` if reusing an existing Devpost project.
3. Fill the Devpost project form: project name, tagline, full description, built-with stack, team status, links, images, and demo video if available.
4. Match the required deliverables from `What The Page Says To Build`: include the live demo URL, repo URL, screenshots, and a short explanation of how the project fits this hackathon's topic.
5. Submit before the deadline shown on Devpost, then reopen the workspace and confirm the project appears under `My hackathon projects`.
